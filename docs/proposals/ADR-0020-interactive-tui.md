# Superseded: interactive TUI decision

This local proposal is superseded by the owner-approved cross-project
[Spec ADR-0020: Frontend topology, TUI-first delivery and presentation contracts](https://github.com/cdin-editor/spec/blob/main/docs/adr/ADR-0020-frontend-topology-and-interaction.md).

Spec FE-009 and FE-011 now accept the full-screen interactive TUI as the first
interactive Frontend target. The non-interactive CLI remains deferred. This
repository's implementation status remains partial; see
[docs/frontends/tui.md](../frontends/tui.md) and
[docs/status.md](../status.md).

Do not use this superseded document as an independent ADR or as evidence that
the TUI application/event loop is complete.
